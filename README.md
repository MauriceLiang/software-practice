# Python 基础练习

NUC 软件工程专业「人工智能软件开发与应用」方向实训的课堂练习仓库。每天（`day01`、`day02`…）一个目录，里面是若干可以单独运行的小脚本，内容从输入输出、数据类型、流程控制，逐步推进到文件读写、JSON、错误处理和模块。

## 目录结构

| 目录 | 内容 |
| --- | --- |
| `day01` | 输入输出、数据类型与转换、f-string 格式化（个人信息卡、名片、四则运算计算器） |
| `day02` | 函数与默认参数、`if/elif/else` 与 `for` 循环、列表与字典操作、列表套字典 |
| `day03` | 文件读写（`open` 的 `w`/`a`/读逐行）、JSON 的 `load`/`loads`/`dump`/`dumps`、`try/except` 错误处理 |
| `day04` | 组合数据类型（元组拆包、`set` 去重、列表套字典）、`random`、`datetime`、自定义模块 |

## 运行

每个脚本都是独立入口，在仓库根目录下这样运行：

```bash
python day01/第一个程序.py
```

- 需要 Python 3，无第三方依赖（`requirements.txt` 为空），clone 下来不用装任何东西。
- macOS 上命令是 `python3`，把上面的 `python` 换成 `python3` 就行。
- 本机开发用的是虚拟环境 `.venv`（Python 3.14.7）。虚拟环境不进版本库，仓库里没有，用自己电脑上的 Python 跑即可。
- `day01` 下的部分脚本用 `input()` 交互式读取输入，运行后需要在终端里输入内容。

## 约定

- 每个脚本的结构一致：逻辑写在 `main()`，文件底部用 `if __name__ == "__main__":` 调用。
- 注释和 docstring 用简体中文，变量名、函数名等标识符保持英文。
- 文件名用中文（如 `day02/列表套字典.py`）。

## 说明

- `day03` 的部分脚本会读写同目录下的数据文件：`class_list.txt`（名单）和 `config.json`（配置）。写文件用的是 `w` 模式，重跑会覆盖上一次的内容。
- `day04/我的工具模块.py` 是被导入的模块，不是独立入口，用 `day04/包与模块练习.py` 调用它。
